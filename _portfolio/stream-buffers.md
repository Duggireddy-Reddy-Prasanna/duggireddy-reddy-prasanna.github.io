#### **Vegetation and Elevation Analysis using Stream Buffers** <a name="vegetation-and-elevation-analysis-using-stream-buffers"></a>

This project applied spatial analysis techniques in **ArcGIS Pro** to investigate the interaction between vegetation cover, topography, and hydrological features. Key tasks included:

- Generating a **vegetation cover classification map**
- Creating **stream buffer zones** at fixed distances
- Performing **intersect analysis** to overlay vegetation and elevation data
- Extracting area summaries by **land cover type using spatial statistics**
- Designing a composite layout with legends, charts, and maps

**Tools used:** *Buffer, Intersect, Clip, Field Calculator, Symmetrical Difference, Spatial Join, Zonal Statistics, Layout Designer.*

#### **Urban Heat Island Analysis** <a name="urban-heat-island-analysis"></a>

This study analyzed spatial temperature variations in urban areas to identify **Urban Heat Island (UHI)** effects. Using remote sensing data and GIS workflows, the study investigated how **land cover, vegetation, and elevation** influence heat retention across the city.  

Key steps included:  
- Mapping surface temperature variations across the city using **thermal remote sensing**  
- Classifying urban land cover types impacting heat retention (residential, industrial, vegetation)  
- Calculating **buffer zones** around major heat sources to analyze temperature gradients  
- Integrating **NDVI and elevation** to assess the role of vegetation and terrain in cooling  
- Producing **maps and charts** for urban planners to identify priority zones for greening interventions  

**Tools used:** *NDVI calculation, Buffer, Zonal Statistics, Raster Reclassification, Spatial Join, Layout Designer.*
